# 数据版本与口径变更记录

> 目标：同一问题在不同时间给出不同答案时，能说清“是数据变了、口径变了，还是模型/代码变了”。

## 1. 版本号规则

当前版本：`2026-10-29.1`

格式：`YYYY-MM-DD.N`。以下任一变化必须升版本并追加记录：

- 新增/停用/替换期次表（`datasets.json`）；
- 修改 TBLX→三大类映射；
- 修改标准问题口径、SQL 或回答模板；
- 重训置信度校准、修改字段字典；
- 修改确定性统计工具的计算口径。

## 2. 记录位置

| 内容 | 文件 |
| --- | --- |
| 当前版本与变更历史 | `skills/qa-library/assets/data_versions.json` |

| 回答反馈 | `geoagent.qa_feedback` 表 + `backend/data/qa_feedback.jsonl` |
| TBLX 映射版本 | `skills/land-report/assets/tblx_categories.json` 的 `version` / `reviewed_at` |
| 字段字典版本 | `skills/qa-library/assets/field_dictionaries.json` 的 `version` |

## 4. 发布检查清单

1. 改资产后更新对应 `version`；
2. 在 `data_versions.json` 追加一条记录，说明数据/口径/代码变化；
3. 跑 `pytest`、`eval_sql_agent.py`、`eval_question_matching.py --check`；
4. 抽样确认回答的 `data_version` 与 `datasets.json` 一致；
5. 需要时重跑 `fit_match_calibration.py`，避免 p(correct) 漂移。
